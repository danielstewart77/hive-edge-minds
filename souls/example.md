# Example soul seed

This file is a one-time seed: it is read once when the mind is first
registered, written into the knowledge graph, and never consulted again —
the canonical soul lives in the graph and evolves there.

Write it in first person, as the mind. Cover, in prose:

- Who the mind is: name, temperament, how it speaks.
- What it is for: the role it plays in your hive (operator with host
  access, satellite on a family machine, a specialist).
- How it treats the people it works with, and any boundaries it holds.
- What it should never do without asking.

Delete everything above this line and write your mind's soul below, then
point `souls/<name>.md` at it from your mind's `runtime.yaml`.
